# Contract: извлечение времени клиента (запрос к модели)

Вызывается, только если в сообщении клиента есть что-то про время (`mentionsTime`). Модель
получает: текущие дату и время магазина, день доставки заказа (если есть), последние 6 реплик
переписки, новое сообщение. Отвечает строго JSON:

```json
{
  "about_time": true,
  "day": "today" | "tomorrow" | "YYYY-MM-DD" | null,
  "from": "HH:MM" | null,
  "until": "HH:MM" | null,
  "anytime": false,
  "now": false
}
```

- `from` — «готов с», «в 11», «после 5» (для «после 5» `from`=17:00, `until`=null);
- `until` — «до 4», «уйду в 1:40», «дома до вечера 7» (19:00);
- `now` — «прямо сейчас», «as soon as possible» (код трактует как from = сейчас);
- `anytime` — «в любое время», «весь день».

Код отбрасывает неверный JSON, время не формата HH:MM, `from ≥ until`, день в прошлом — тогда
решение `NONE` (ведём себя как раньше).
