# Quickstart: как проверить планирование времени

## Юнит-тесты

```bash
export PATH="$HOME/.nvm/versions/node/v24.18.0/bin:$PATH"
npx vitest run src/modules/timing src/modules/assistant src/lib/deliveryWindow.test.ts
```

## Сверка расписания с фактом (только чтение)

```bash
NODE_OPTIONS=--conditions=react-server npx tsx scripts/timing-backtest.ts --days 14
```

Печатает по дням: сколько доставок, сколько опоздали, где расписание видело риск; итог — медиана
«факт минус план» и доля доставок, приехавших позже плана больше чем на 20 минут.

## Тестовая база (`floremart_uitest`, порт 3111)

1. `preview_start floremart-uitest`, войти владельцем.
2. «Флористы»: «Начинает работу в» — у Насти 10:00, у Ольги 12:00; смена сохраняется сразу.
3. «График доставки → План по дням»: у флориста «Новый заказ — к HH:MM», очередь с номерами,
   «по плану к …», красным — «не успеваем на …»; внизу «Как считаем время».
4. «Как успели»: факт доставки против окна, опоздание до 20 минут — «нормально».
